
\# SENTINEL AI - Network Intrusion Detection System



\## Project Overview

SENTINEL AI is a machine learning-based network intrusion detection system that classifies network traffic as normal or anomalous.



\## Features

\- Network traffic classification

\- Machine learning-based intrusion prediction

\- Interactive Streamlit dashboard



\## Technologies Used

\- Python

\- Pandas and NumPy

\- Scikit-learn

\- Streamlit

\- Joblib



\## Machine Learning Models

\- Logistic Regression

\- Random Forest

\- Gradient Boosting



\## How to Run

1\. Install dependencies:

&#x20;  pip install -r requirements.txt



2\. Run the application:

&#x20;  streamlit run app.py
